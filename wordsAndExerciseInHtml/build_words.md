# Skill: Build HTML Words & Exercises

Rebuild the static HTML study pages for N2 vocabulary words and unit exercises.

## What this skill manages


```
wordsAndExerciseInHtml/
  index.html                      ← landing nav (Words + Exercises)
  build_html.py                   ← THIS SCRIPT — rebuilds word pages
  words/
    index.html                    ← unit grid (13 units, total count)
    by_unit/
      unit_01.html … unit_13.html ← one page per unit, all entries
  exercises/
    index.html
    n2/
      unit01/ … unit13/           ← unit exercise pages with answer keys
      matome1/                    ← summary exercise pages
```

## Data sources

| What | Path | Notes |
|------|------|-------|
| Vocabulary text | `vocabulary.json` (project root) | 1142 entries, all units |
| Audio clips | `clips/unitX_trackYY/wordN.mp3` + `sentenceN.mp3` (project root) | separate word and sentence files |
| Exercise JSON | `json/page_*.json` | parsed OCR pages, type=exercise/answer_key |

### vocabulary.json entry schema

```json
{
  "index": 1,
  "unit": { "number": 1, "header": "Unit 01 名詞 A" },
  "reading": "じんせい",
  "kanji": "人生",
  "headword_text": "人生",
  "verb_pattern": null,
  "meaning_en": "",
  "meaning_zh": "",
  "sentence": "幸せな人生を送る。",
  "examples": ["人生経験が豊富な人の話は面白い。"],
  "word_clip": "clips/unit1_track02/word001.mp3",
  "sentence_clip": "clips/unit1_track02/sentence001.mp3",
  "explanation": "**To live...** \n\n---\n\n- **人生** — noun..."
}
```

> **Note:** `word_clip`/`sentence_clip` paths are relative to the project root, e.g. `clips/unit1_track02/word001.mp3`.
> Subdirectory names follow the pattern `unitX_trackYY`; numbering is global across the whole book.

## Rebuild word pages

Run from the **project root**:

```bash
python wordsAndExerciseInHtml/build_html.py
```

Writes 15 files: `index.html`, `words/index.html`, and `words/by_unit/unit_01.html`
through `unit_13.html`.

## Rebuild exercise pages

Exercise pages are generated by a separate script:

```bash
python parse/scripts/convert_n2_exercises.py
```

That script reads `json/page_*.json` (OCR output) and writes into
`wordsAndExerciseInHtml/exercises/`.

## When to rebuild

- **After adding/editing explanations** in `vocabulary.json` → run `build_html.py`
- **After new audio clips are cut** → run `build_html.py` (paths update automatically)
- **After re-OCRing exercise pages** → run `convert_n2_exercises.py`

## Audio path resolution

Clips are at `clips/unitX_trackYY/wordN.mp3` (and `sentenceN.mp3`) relative to the project root.
From `wordsAndExerciseInHtml/words/by_unit/`, that's three levels up:

```
../../../clips/unit1_track02/word001.mp3
```

`build_words.py` handles this via `clip_rel_path()` which prepends `../../../` to the
path stored in `vocabulary.json`.

## Explanation markdown format

The `explanation` field uses lightweight markdown rendered by `explanation_html()`:

| Syntax | Output |
|--------|--------|
| `**text**` | `<strong>` bold |
| `*text*` | `<em>` italic |
| `- item` | `<ul><li>` list |
| `\n---\n` | `<hr>` section divider |
| `[JLPT N2]` | styled badge |

## Adding a new unit

1. Add entries to `vocabulary.json` with the correct `unit.number` and `unit.header`
2. Add audio clips to `clips/unitX_trackYY/` following the `wordN.mp3` / `sentenceN.mp3` naming convention
3. Run `build_words.py` — a new `unit_XX.html` is created automatically
